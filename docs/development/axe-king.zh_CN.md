# 飞哥玩斧王

本树编出的固件是一款离线小游戏。`app_main` 直接进入游戏画面，不打开基线硬件测试菜单。`main/` 里的 demo 源文件仍留给既有 host 测试，不会链进应用程序。画面是用 LVGL 基本图形画的夜间竞技场，不使用 `ui_pixel` 面板、demo 吉祥物或测试菜单外壳。

## 玩法

屏幕为 240×320。产品规格把三个键称为上、下、确定。本游戏把上键当作音量加、下键当作音量减。这是操作约定，不修改 `bsp_pins.h`。

1. 封面。大幅原创斧王立绘、标题「飞哥玩斧王」和提示「按任意键继续」。任意键开始一局。
2. 准备，5 秒。红色斧王棋子比每个小兵略大，十个绿色小兵聚在一个固定半径的圆里。斧王团和小兵团每局重新随机落点。斧王原地旋转，同样半径的半透明红圈以斧王为中心闪烁。状态栏左侧是「飞哥快上！」，右侧是倒计时。
3. 瞄准。小兵隐藏，斧王留在原位。音量加顺时针转箭头，音量减逆时针转；按住持续旋转。确定锁定方向。随后距离标记沿箭头伸缩，再按确定锁定当前距离。
4. 结算。小兵回到准备阶段的位置，斧王跳到锁定落点，在新位置画出同样半径的圆，圆心落在圆内的小兵变成红色。
5. 结果。立绘表情按命中数变化：0 双手抱头，1–3 哭泣，4–6 发呆，7–9 墨镜，10 露出牙齿。评语从与命中数对应的一档里随机抽取，并且都以「飞哥，你」开头。确定回到封面，开始下一局。

不初始化 Wi-Fi 和蓝牙，游戏本身不写 NVS。从 `0x0` 烧录合并镜像仍可能重置 NVS 区域，见[烧录与已存数据](engineering/firmware-layout.zh_CN.md#烧录与已存数据)。

电量指示放在右下角，避免挡住倒计时。`bsp_battery_soc()` 为 `-1` 时画空电量并显示 `--`，不编造百分比。封面无操作 30 秒后背光从 80% 降到 8%，下次按键恢复。

## 字体

Montserrat 14 和 20 没有中日韩字形。游戏链接 `assets/fonts/axe_king_font_16.c` 与 `assets/fonts/axe_king_font_24.c`：4 bpp、LVGL 9.5、PLAIN、stride 0。`tools/gen_axe_font.py` 用文泉驿微米黑光栅化（Apache-2.0 或带字体例外的 GPL-3.0）。源字库文件不入库。重新生成：

```bash
python3 tools/gen_axe_font.py --font /usr/share/fonts/truetype/wqy/wqy-microhei.ttc
```

`tests/test_axe_glyphs.py` 要求游戏源码里的每个字符串（含 ASCII）都进入两种字号，并要求 U+9F98 不在子集中。每个文字控件都显式选用这些字体。host 检查通过不等于真机已经画出这些字。

## 逻辑测试

`tests/test_axe_logic.c` 覆盖圆内判定（含边界）、从正上方起顺时针的落点、距离伸缩、分数分档、评语前缀和每局摆放。它不包含 ESP-IDF 或 LVGL 头文件。
